## Prompt

**Folder:** `project6/` · **Vibe:** the most minimal

A single command prompt. Switching pages erases the old output bottom-up, retypes the command, then prints the new lines one by one.

- **Pages:** home · portfolio · contact
- **Interactions:** press `h`, `p` or `c` anywhere on the page to navigate — the keys are shown in the bar at the bottom.
- **Detail:** content lives in `<template>` tags, so the script just prints them.
- **Tech:** JetBrains Mono only, violet accent (`#9C82F5`).
