## Grid

**Vibe:** modern dashboard, agency-like

A full-screen grid of bordered cells with a fixed sidebar — the kind of layout you see on design-studio sites.

- **Pages:** home · portfolio · contact
- **Layout:** cells fill the whole viewport; project cards go four-across on wide screens, two on laptops, one on phones.
- **Interactions:** cells fade in one after another when you switch pages, hover highlights, live Manila clock cell.
- **Tech:** DM Sans + DM Mono, green accent (`#4FB57E`).
